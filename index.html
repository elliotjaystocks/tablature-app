Settings

Your songs are saved as files in a GitHub repository, so you’ll need a personal access token that lets this app write to it. Everything here is stored in this browser only.

How to create a token
  1. Go to GitHub → Settings → Developer settings → Fine-grained tokens.
  2. Under Repository access, choose Only select repositories and pick this app’s repo.
  3. Under Permissions, set Contents to Read and write.
  4. Generate the token and paste it below.

Create one at console.anthropic.com, and set a monthly spend limit there.
